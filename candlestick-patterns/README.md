# 38 Candlestick Patterns

This folder contains 38 original candlestick-pattern illustrations created for this repository.

Pattern names were compiled from the Groww article:
https://groww.in/blog/candlestick-patterns

## Notes
- The SVG illustrations in this folder are original repository assets and are **not copies of Groww's image files**.
- They are intended for educational/chart-pattern reference use.
- `patterns.json` provides a machine-readable index for app integration.
