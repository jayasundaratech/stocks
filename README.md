# Dynamic Market Charts Demo

A small public web app inspired by a multi-chart trading dashboard.

## Features

- Four independent chart panels
- Candlestick + volume rendering
- Symbol search and switching
- Multiple timeframes
- Simulated live price updates
- Responsive desktop/mobile layout
- No backend required

> The market data in this project is simulated for learning and UI testing. It is not live trading data and is not financial advice.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Public deployment

This repository includes a GitHub Pages deployment workflow. After GitHub Pages is enabled with **GitHub Actions** as the source, pushes to `main` will deploy the site automatically.
